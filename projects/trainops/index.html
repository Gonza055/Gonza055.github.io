    Simulation Data to Operational Insights.

    I built Python and C++ automation workflows that transformed large TrainOps simulation outputs into cleaner, repeatable datasets for scenario comparison, network analysis, and planning support.

    Python C++ Data Engineering Simulation Analytics
    RoleData Analytics Intern
    OrganizationHatch Urban Solutions
    LocationVermont · USA
    PeriodMay – Aug 2024
    DomainTransportation simulation

    The Problem

    Large simulation outputs were slowing down the analysis loop.

    TrainOps scenarios produced large, fragmented output sets that required repeated processing before analysts could compare delays, network behavior, service assumptions, and operational bottlenecks.

    The recurring task was not only to run simulations. It was to make the outputs consistent, analysis-ready, and comparable so more time could be spent interpreting the scenario rather than rebuilding the same preparation workflow.

    Core engineering question

    How can raw simulation output become a repeatable analytical pipeline that supports faster scenario evaluation?

    Data Pipeline

    Raw outputs → structured datasets → scenario comparison.

    The work focused on standardizing the repetitive parts of simulation analysis so that the same preparation logic could be reused across cases.

    01 · ParseRead large TrainOps output files and extract the fields needed for analysis.
    02 · StructureNormalize fragmented outputs into consistent, analysis-ready datasets.
    03 · EnrichCombine simulation results with rider-survey responses and onboard sensor data where relevant.
    04 · CompareEvaluate delays, network performance, service configurations, and operational bottlenecks across scenarios.

    Beyond the Simulation File

    Outcome

    Less manual processing. More time for operational analysis.

    The automated workflow reduced simulation-output processing time by approximately 70%, improved repeatability, and shifted more attention toward comparing scenarios and interpreting planning implications.

    Faster iteration

    Reduced repetitive parsing and preparation between simulation cases.

    More repeatable

    Standardized transformations reduced dependence on one-off manual workflows.

    Broader context

    Survey and sensor inputs complemented the simulation results.

    Better decision support

    Analysts could spend more time interpreting operational tradeoffs across scenarios.

    What I Learned

    Automation creates value when it gives analysts more time to understand the scenario.

    The most useful automation did not replace engineering judgment. It removed repeated data-preparation work so that more attention could go to understanding operational behavior, comparing alternatives, and supporting planning decisions.
