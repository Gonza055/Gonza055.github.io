    Operational Mode Discovery Using Unsupervised Learning

    The thesis investigates whether a mineral-processing circuit behaves as one broad operating state or as several recurring regimes that can be discovered from minute-level process variables and then interpreted using metallurgical and production KPIs.

    RESEARCH QUESTION

    Does the plant operate as one state — or as several recurring operating modes?

    The process variables define the analytical structure. Recovery, production, and metallurgical KPIs are attached afterward to interpret the regimes — not to generate them.

    WHAT I LEARNED

    A cluster is not an insight until it has operational meaning.

    Unsupervised learning can reveal structure in complex process data, but the real value comes from connecting those patterns back to process behavior, KPIs, physical equipment, and operational decisions.
